# code2prompt

**Pack your code. Feed your AI. Build faster.**

ContextPack is a Visual Studio Code extension that lets developers quickly copy files and folders into an AI-friendly format.

Stop manually copying multiple files when working with ChatGPT, Claude, Gemini, or other AI coding assistants.

Select → Copy Context → Paste into AI.


---

## ✨ Features

### 📄 Copy Single Files

Right-click any file and instantly convert it into structured AI context.
